# brand-config

Reads this package's brand identifiers (package name, agent prefix, orchestrator name, and related fields) from `lib/constants.json` instead of hardcoding them in each script. Part of the Konductor rebrand implementation plan, Phase 1.

A future rename of these identifiers becomes a change to `lib/constants.json`'s values only. No script that requires this directory needs to change.

## Files

| File                 | What it does                                                                                               |
| -------------------- | ---------------------------------------------------------------------------------------------------------- |
| `lib/constants.json` | This package's own brand identifiers as flat JSON fields. See "Fields" below.                              |
| `lib/constants.js`   | Wraps `constants.json` with `isAgentSpecFilename()`, the one piece of matching logic every consumer needs. |

This package's own `lib/constants.json` never contains a brand-prefix string belonging to this package's internal counterpart -- its copy of this same directory is a separate file, not a shared one. This package is the public base and its safety scan fails the build on any reference to that internal counterpart's name, so a single shared constants file could never ship here.

## Fields

| Field                    | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `package_name`           | This package's own package name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `orchestrator_agent`     | The bare name of this package's orchestrator agent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `orchestrator_variants`  | A list of orchestrator variant names (for example, the mux and cmux orchestrators).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `agent_prefix`           | The prefix shared by every non-orchestrator agent in this package.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `retired_agent_prefixes` | Optional. A list of prefixes this package used to declare via `agent_prefix` (or an orchestrator field above) before a rename moved it off that scheme -- for example, `["asdlc"]` after the Konductor rebrand moved this package off the `asdlc-*` naming scheme. Not read by `constants.js`/`isAgentSpecFilename()` (a retired prefix has no place in "does this name belong to the package's CURRENT scheme"); consumed only by this package's internal counterpart's own rebrand-verification gate, so a stale, un-cleaned reference to the retired prefix stays recognized as agent-shaped after the rename that retired it. |
| `skill_prefix`           | The prefix used for this package's skill names.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `install_prefix`         | The prefix AIM uses for locally-installed agent files.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `bench_model_env`        | The name of the environment variable that pins the subject model for benchmark runs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `max_inline_chars_env`   | The name of the environment variable that sets the per-agent skill-inline character budget.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `claude_agents_dir_env`  | The name of the environment variable that overrides the installed Claude Code agents directory.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `plugin_namespace`       | The AIM plugin namespace this package installs under.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

The naming scheme has three overlapping patterns: a bare orchestrator identifier, a small fixed set of orchestrator variants, and every other agent sharing `agent_prefix`. Before the Konductor rename all three happened to share the same `agent_prefix`, so a naive `f.startsWith(agent_prefix)` check worked by coincidence. That coincidence is gone: `orchestrator_agent` is now `konductor` and `agent_prefix` is `k-`, and `"konductor".startsWith("k-")` is false, so the naive check would miss the orchestrator outright. `isAgentSpecFilename()` checks all three patterns, which is why the rename needed no code change here — only a `constants.json` value change.

## Usage

```javascript
const {
  CONSTANTS,
  isAgentSpecFilename,
} = require('./brand-config/lib/constants.js');

isAgentSpecFilename('k-developer.agent-spec.json'); // true
```

`constants.js` calls a validation step at module load that rejects a missing field, a field of the wrong type, or an explicitly empty string or array. An empty value would otherwise pass JSON parsing and a plain `field in data` presence check, then silently widen every glob or path built from it. This throws at require time, so a broken `constants.json` fails loudly instead of producing a silently over-broad match later.
