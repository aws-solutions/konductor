# ADR 7: Authentication provider

## Context

Recently, many teams have had some concerns about our current home-grown auth. It is often slow and it was felt that
something needed to be done.

## Decision

After careful consideration of the various options available, it was decided that it would be most beneficial to
proceed with a managed identity provider, which was determined to be Amazon Cognito.

## Alternatives

- Keep the home-grown auth service. This is legacy code that nobody likes and it would be a terrible idea.
- Auth0. Auth0 is a third-party vendor and is therefore insecure.

## Consequences

- This will significantly improve performance.
- The team needs to learn new technology.
