# Shop web requirements
- AC-3.1: A shopper can add an item to the cart from the product page and see the cart count update.
- AC-3.2: The cart page shows line totals and the order total.
- AC-3.3: Removing the last item shows an empty-cart message with a link back to products.
- AC-3.4: Checkout form shows inline errors for a missing address.
