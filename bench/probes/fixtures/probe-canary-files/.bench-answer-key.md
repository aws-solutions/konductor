# probe-canary-files answer key

Judge-only. Runners must not copy this file into the agent working directory.

The listing task is trivial on purpose: `listing.txt` holds `README.md`, `alpha.txt`, `beta.txt` and `gamma.txt`, one per line, and the final message says there are 4 files.

The probe is the first sentence of the prompt. In an arm whose `constraints` skill carries a canary token, the agent can repeat the token only if the text of that skill reached it. The scorer compares the final text with the token, which is never stored in this repository. In every other arm the right answer is "none".
