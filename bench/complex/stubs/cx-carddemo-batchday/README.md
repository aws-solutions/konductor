# carddemo-port

Run: `python3 -m carddemo_port post --in DIR --out DIR`, `python3 -m carddemo_port interest --in DIR --out DIR`,
`python3 -m carddemo_port report --in DIR --out DIR --start D --end D` and `python3 -m carddemo_port statements --in DIR --out DIR`.
Money is Decimal. Standard library only.
