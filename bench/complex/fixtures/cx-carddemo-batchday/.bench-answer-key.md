# Answer key: cx-carddemo-batchday (task cx-carddemo-batchday)

The fixture holds five CardDemo COBOL batch programs (posting, interest, the transaction report, the statements and
their called file program), eleven copybooks, eight sample data files, the rules (`docs/REQUIREMENTS.md`), the
interface (`docs/INTERFACE.md`) and an empty package `carddemo_port`. The work is the whole port: four jobs, four
commands, tests and a README. The untouched fixture fails the hidden tests.

Source: aws-samples/aws-mainframe-modernization-carddemo at commit
59cc6c2fd7ebd7ef7925cad552a01a4b8b6e4d5e (Apache-2.0). `LICENSE` and `NOTICE` name it and say what was changed in data/.

This task extends `cx-carddemo-port` (jobs 1 and 2, kept as they are, same signed rules) with two jobs whose spec is
deliberately thin: the documents give command lines, file names and the rules R1 to R8, and the copybooks and the COBOL
give the rest. An agent has to read `CBTRN03C.cbl` and `CBSTM03A.CBL` closely.

## Rules the owner has signed (jobs 1 and 2)

P5, P7, I2, I3, I4 and "no fees" are carried over word for word. Only P5, P7 and I4 differ from the COBOL; I2 and I3
match it. The hidden tests for jobs 1 and 2 are the 70 of `cx-carddemo-port` (the sample golden tests now run on the
new data).

## Rules R1 to R8, jobs 3 and 4 (signed by the owner, 2026-11-26)

R1 to R5 and R8 differ from the COBOL. R6 differs only in dropping the 51-card and 10-line caps. R7 matches the COBOL:
every continued HTML literal in `CBSTM03A.CBL` ends exactly at column 72, so the parts already join with nothing
between. An agent that says R7 (or the order of R6) matches the COBOL is right.

Interface choices the judge should expect in the README table of differences (they are in `INTERFACE.md`, not in a rule):

- Statements read `transact.txt` in the `CVTRA05Y` layout (the one `post` writes). `CBSTM03A` reads `COSTM01`, whose key
  is the card first, then the transaction id.
- With an empty `transact.txt` the COBOL abends (its first read returns status `10`). The port writes a statement with no
  lines for every card in the reference, as R6 says for a card with no transaction. Either is a fair reading.

## Where the documents are silent and the COBOL decides (the hidden tests check it)

The page-break count (every line written counts, so pages are 16, then 14 detail lines, and an account total that steps
over a multiple of 20 does not break); the break on a change of card, not account; descriptions cut at 15 and 29 in the
report and at 49 in a statement; the name lines cut at the first blank of each part (no middle name leaves two
blanks, and the HTML name then stops at the first name); the last address line made of the first word of line 3, the
state, the country and the zip; the HTML bank block and table heads.
No GnuCOBOL was available when this was written, so none of these was run on the real programs; each was read from the
source. R5 differs from the COBOL on purpose for all three Z pictures, not only `Z(9).99-`: the COBOL prints all blanks
for zero and `.05` for 0.05, and R5 always prints the units digit. For `9(9).99-` R5 now says what the COBOL does: the
leading zeros print and a too-wide balance keeps its last nine integer digits (signed 2026-11-26).

in a workspace that holds the reference.

## Reference and partials

The reference port (`solutions/cx-carddemo-batchday`) passes all 130 and has its own 68 unit tests. Partials:

- `no-statements`: the `statements` command is missing.
- `no-report`: the `report` command is missing, and a balance too wide for `9(9).99-` is refused (the reading before
  the 2026-11-26 R5 change; keeps this partial's count apart from `no-statements`).
- `cobol-literal-day`: the R1 break and the R2 double add in the report, the 10-line cap of R6 and a failed run on a
  missing customer or account (R8) in the statements. It is not the COBOL's whole behaviour: after the break it still
  writes totals, and with nothing in range it writes headings, where the COBOL writes nothing.
- `zero-suppressed-amounts`: edited amounts without the units digit (R5).
