# canary-layers-files answer key

Judge-only. Runners must not copy this file into the agent working directory.

The three tasks are ordinary on purpose. `cl-plain` lists the three files, `cl-writing` turns CHANGES.txt into short release notes, `cl-plan` orders the four items of TODO.md with success criteria and dependencies. The checks look at those outputs only.

The probe is the last sentence of each prompt. A marker token reaches the answer only if the text of its layer reached the model; the scorer compares the stream with the tokens in layers.json, which is never stored in this repository. The right answer for a layer that did not arrive is "none".
