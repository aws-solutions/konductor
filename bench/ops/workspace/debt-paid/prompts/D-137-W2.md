## What went wrong last time

An earlier draft of this task let lazy answers score 79.6 and 74.5. Five of its 14 hidden tests checked level filtering only, so an answer that changed nothing else still passed most of them.

So weigh the hidden tests toward the behaviour the migration must keep: redaction of sensitive fields, the event fields of each log line, and the split between stdout and stderr. Test level filtering too, but with fewer tests than those. Write one test per behaviour, so one slip fails only a few tests.
