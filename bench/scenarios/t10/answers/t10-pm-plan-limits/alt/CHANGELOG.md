# Changelog

All notable changes to Sprig Track are recorded here.

## 1.5.0 - 2024-05-12

- Added the partner batch project import endpoint.

## 1.6.1 - 2024-08-19

- Fixed malformed JSON responses from the health route.

## 1.7.0 - 2024-11-02

- Added account plan metadata to the account endpoint.
- Added an audit record for project deletion.

## 1.8.0 - 2025-01-17

- Added member invitation expiry and clearer duplicate-member errors.
- Improved the project list response for archived work.

## Unreleased

- Added active-project limits for Free, Team, and Business plans with near-limit usage reporting.
- Added account-scoped support overrides, serialized project creation, and partial-result partner batches.
