# Changelog

## 2.4.0 - 2025-02-18
- Added the delivery postcode availability check and a retry affordance.
- Added order progress updates after the payment gateway accepts a charge.
- Kept the signed-in checkout available when shoppers refresh the page.

- Reworked the cart panel to show quantity controls beside each product.
- Added a compact failure dialog for gateway and address errors.

- Switched displayed prices to the store's two-decimal currency format.
- Added keyboard-friendly focus styles to the checkout panels.

## 2.2.4 - 2024-12-12
- Removed the old promotional banner and refreshed the empty-cart copy.
