# Keyboard map

| Key | Meaning |
| --- | --- |
| `n` | Start a new card in Inbox |
| `e` | Edit the selected card |
| `Backspace` | Remove the selected card |
| `Escape` | Leave the current edit |
| `ArrowRight` | Move the selected card one column forward |
| `ArrowLeft` | Move the selected card one column backward |
| `z` | Undo the last board change |

Commands are ignored when there is no selected card, except for `n`, `Escape`, and `z`.
