# Changelog

## 2.4.2 - 2024-11-15

- Fixed overlap detection to treat end instant as free, allowing bookings starting at the end time of a previous booking.
- Fixed monthly report to include the 31st of the month.
- Fixed night count calculation to handle daylight saving time transitions correctly.

## 2.4.1 - 2024-11-12

- Added the room name to monthly report rows.
- Improved command-line messages for missing input files.

## 2.4.0 - 2024-08-19

- Added support for importing bookings exported by the front desk spreadsheet.
- Documented the training room in the sample data.

## 2.3.0 - 2024-04-03

- Added a monthly occupancy report.
