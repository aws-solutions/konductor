# Changelog

## 1.4.2 - 2025-02-14

- Migrated from bundled Gridline 1 to Gridline 2 renderer.
- Table output now uses plain numeric formatting by default.
- CSV output now ends with a newline and properly quotes values with commas, quotes, or line breaks.
- Compact mode now produces tab-separated rows without headings.

## 1.4.1 - 2025-01-20

- Made invalid input errors include the source filename.
- Updated the sample sales export.
