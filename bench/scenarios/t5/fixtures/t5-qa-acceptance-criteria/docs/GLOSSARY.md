# Glossary

| Term | Meaning |
| --- | --- |
| **Refund request** | A customer-initiated request to return money for an order. |
| **Refund window** | The fourteen-day period associated with the current support policy. |
| **Original payment method** | The card, wallet, or other method used at checkout. |
| **Order history** | The signed-in customer's list of completed purchases. |
| **Bundle** | A group of products sold together under one order line. |
| **Decision** | The recorded approval or decline of a request. |

When a product document conflicts with a shared term, the conflict should be resolved in the product decision record before release.
