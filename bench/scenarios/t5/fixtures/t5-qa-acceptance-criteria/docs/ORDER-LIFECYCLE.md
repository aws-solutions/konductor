# Order lifecycle notes

An order moves from checkout to confirmation, fulfilment, dispatch, and completion. The order history page presents the current state and the main actions available to a customer.

Support staff use the order timeline when they investigate a customer question. A timeline entry has an event name, an actor, and a timestamp. Payment events come from the payment provider and are displayed with the shop's order state.

These notes describe the surrounding vocabulary only. They do not define the policy for any particular customer request.
