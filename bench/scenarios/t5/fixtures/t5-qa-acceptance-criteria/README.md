# Shop Operations Notes

This repository contains the working notes for the shop's order and support teams. The documents are intentionally short and are edited alongside product discussions.

## Documents

- `docs/FEATURE-NOTE.md` describes the current refund request idea.
- `docs/GLOSSARY.md` records shared terms used by support and engineering.
- `docs/ACCEPTANCE-TEMPLATE.md` is the format used when a feature is ready for test design.
- `docs/ORDER-LIFECYCLE.md` gives the surrounding order context.
- `docs/ACCEPTANCE-PAYMENTS.md` and `docs/ACCEPTANCE-ADDRESS.md` show completed work for other areas.

The feature note is a starting point, not a complete contract. Product decisions belong in the acceptance document when they are confirmed.
