# Aurora Wallet launch folder

This folder holds working material for the Aurora Wallet regional release. It contains readiness notes, operating data, and the current handoff record. The launch owner should treat generated metrics and logs as read-only evidence.

The target regions are Noria, Solmere, Kestrel, and Veyra. Service names in the operational data are `wallet-session`, `edge-api`, and `partner-adapter`.

The `docs/` notes are the decisions and commitments in force for this release. `ops/` contains sampled service evidence and deployment records. The scripts are small utilities left by the operating team and do not need installation.
