# Orders database operations folder

This folder contains the working material for the orders database service. It includes the current topology and client settings, the replication manager reference, alert and metric definitions, operational policy, paging contacts, generated service history, and notes from earlier incidents.

The service uses a small open-source replication manager named QuorumCtl. The vendored help is the authority for command spelling and flags. Values in the generated histories are UTC.

Some documents are historical or stale. Check dates, ownership, and the live configuration before relying on them during an incident.
