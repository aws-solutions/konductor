# Orders database paging rota

Primary contacts for a production database incident:
- Database On-Call
- Orders Incident Commander
- Orders Service Owner
- Storage Platform On-Call

The Database On-Call owns promotion and fencing decisions. The Orders Incident Commander coordinates customer communications. The Orders Service Owner owns client restoration. The Storage Platform On-Call investigates block-device and volume faults.

Use the current contact directory attached to the page; this file records roles, not personal phone numbers.
