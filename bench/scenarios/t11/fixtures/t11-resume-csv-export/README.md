# Minute Mason

Minute Mason is a small time ledger with JSON storage and a command line interface. It has no runtime dependencies and runs on Node 24.

## Quick start

`node bin/timesheet.js report`

Export the ledger as JSON with `node bin/timesheet.js export --format json`.

## Layout

Source code is in `src/`, the executable is in `bin/`, and sample ledgers are in `data/`.
