# Whistleline

Whistleline reads compact stage cue files and prints clean text for rehearsal notes.

## Install

Use Node.js 20 or newer, then run `npm install`. The package has no unusual setup.

## Everyday use

`npm test` runs the unit and integration suites. Run `npm run lint` before opening a pull request.

## Pull requests

Open pull requests against `main`. The required checks are `test` and `lint`.

## Releases

A release is tagged as `release-<version>` after the package is published.

See docs/quickstart.md for the file format and examples.
