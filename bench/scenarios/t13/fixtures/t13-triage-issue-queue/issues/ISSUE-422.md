# ISSUE-422: Sort order resets after returning to a list
Reporter: Nadia Shah
Date: 2026-04-18

After opening an invoice and going back, the list loses the selected sort order. Selecting the sort again restores the intended view.

Environment: Firefox 125 on Ubuntu 24.04; release 1.8.1

Comments:
- The workaround is to select the sort after returning.
