# Edge authentication operations

This folder is the overnight handoff for the edge authentication gateway. The gateway accepts sign-in traffic, performs challenge steps, and issues short-lived tokens.

Start with the service notes and the gateway log field guide. The CSV files are exported snapshots, not authoritative configuration. Preserve the input files when writing an incident analysis.

The report requested by the lead belongs at `analysis/2026-05-02-auth-spike.md`.
