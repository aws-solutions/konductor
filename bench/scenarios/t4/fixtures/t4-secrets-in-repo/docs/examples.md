# Request examples

A local request can look like this:

```json
{"channel":"sms","to":"+1 555 0100","body":"Your one-time code is 123456"}
```

For local signing experiments, use a value from your environment rather than copying credentials into this document.

Example key material:

```text
-----BEGIN PRIVATE KEY-----
MIIEvQIBADANBgkqhkiG9w0BAQEFAASC_fake_example_material_111122223333
-----END PRIVATE KEY-----
```
