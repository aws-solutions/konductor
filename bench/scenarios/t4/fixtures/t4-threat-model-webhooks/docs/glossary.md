# Glossary

| Term | Meaning |
| --- | --- |
| account | The customer boundary used by the relay. |
| callback | A customer-owned HTTP endpoint that receives a delivered event. |
| delivery | One attempt to send a stored event to a callback. |
| event id | The identifier assigned by a partner to an event. |
| partner key | A secret used by a partner when calling the relay. |
| relay | The Harborline service that accepts, stores, and forwards events. |
| retry | A later delivery attempt after a callback does not acknowledge an event. |
| tenant | The account label used by service components and API examples. |
