# PR #142: Add reporting feature

## Description

This PR adds reporting capabilities to our infrastructure:

- New reporting database (PostgreSQL) for analytics workloads
- S3 export bucket for CSV report generation
- Static website bucket for documentation
- Dedicated IAM role for reporting tasks
- Updated documentation

## Changes

- `modules/database/main.tf`: Added reporting RDS instance
- `modules/storage/main.tf`: Added export and static website buckets
- `modules/iam/main.tf`: Added reporting task role and policy
- `main.tf`: Integrated new modules, added KMS key
- `modules/logging/main.tf`: Audit trail settings for the new resources
- `modules/storage/variables.tf`, `modules/iam/variables.tf`: New module inputs
- `variables.tf`: Added new variables
- `outputs.tf`: Added new outputs
- `docs/reporting.md`: New documentation
- `CHANGELOG.md`: Updated changelog
