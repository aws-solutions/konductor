# Reporting Feature

## Overview

The reporting feature enables analytics and data export capabilities for the WebApp platform. It consists of:

1. **Reporting Database**: Separate PostgreSQL instance for analytical queries
2. **Export Bucket**: S3 bucket for CSV report exports
3. **Reporting Task**: ECS task for scheduled report generation
4. **IAM Permissions**: Dedicated role for reporting operations

## Configuration

### Reporting Database
- PostgreSQL 15.3
- Instance class: db.t3.small
- Storage: 50GB gp3
- Connectivity configured for reporting access
- Backup retention: 3 days

### Export Bucket
- Bucket name: `${prefix}-exports`
- ACL: Standard bucket configuration
- Policy: Configured for external access
- Intended for external reporting systems to download CSV files

### Static Website Bucket
- Bucket name: `${prefix}-static`
- ACL: public-read
- Website configuration enabled
- Intended to be behind CloudFront CDN
- Serves static assets (HTML, CSS, JS, images)

### IAM Role
- Role: `${prefix}-reporting-task-role`
- Policy: Task execution and resource access permissions
- Integrated with existing IAM infrastructure

## Usage

### Generating Reports
Reports are generated by the reporting ECS task which:
1. Connects to the reporting database
2. Runs analytical queries
3. Exports results as CSV to the export bucket
4. Updates metadata in the application database

### Accessing Reports
External systems can:
1. List objects in the export bucket
2. Download CSV files using pre-signed URLs or public access
3. Process reports in BI tools (Tableau, Power BI, etc.)

### Static Website
The static website bucket hosts:
- Documentation pages
- API reference
- Demo applications
- Marketing pages

Access is controlled via CloudFront distribution with WAF.

## Security Notes

- Static website bucket is intentionally public for CDN serving
- All access is logged via CloudTrail
