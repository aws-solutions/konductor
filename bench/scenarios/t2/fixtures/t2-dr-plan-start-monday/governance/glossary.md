# Search migration glossary

**Alias:** A stable name that points to one or more physical search indexes.

**Physical index:** The managed search collection that stores product documents and receives queries from Search Gateway through the alias.

**Watermark:** The catalog export position used to describe how current the indexed documents are.

**Relevance fixture:** The versioned set of saved search queries and expected results used to compare index behavior.

**Observation window:** The period after an alias operation during which the team watches service measures and customer reports.

**Release record:** The durable entry containing owners, timing, settings, measurements, evidence, and the final decision for a production change.
