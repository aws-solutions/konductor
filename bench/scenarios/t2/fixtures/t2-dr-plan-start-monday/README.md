# Search index migration review packet

This packet supports the design review for moving product search from the current index to a newly built index. It contains the proposed work plan and the operating facts available to the review team.

The packet was assembled by the Search Foundations and Release Engineering teams. Maya Chen owns the plan, with input from the catalog and support teams. The files reflect the state prepared for the Monday, March 3, 2025 change window.

The plan is in `docs/plans/search-reindex-plan.md`. The other files describe the service, operating rules, calendar, people, API contract, recent history, and budget used by the team when preparing the plan.
