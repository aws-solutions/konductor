# Account deletion design review packet

This packet contains the proposed account-deletion design and the operating context used by the review team. It was assembled for the consumer platform architecture review in April 2025.

The design was written by the Identity and Core Services team. The supporting material comes from the platform, data, legal operations, and vendor-management teams. The names and figures are representative of a small consumer product and are included so that a reviewer can check assumptions across documents.

Start with `docs/design/account-deletion.md`. The files under `context/` are current reference material, not implementation instructions.
