# Notification preferences design packet

This packet is the working material for a design review of the notification-preferences change. It was assembled by the Notifications Platform team from the product brief, current service notes, operating targets, and a recent incident summary. The document under review is `docs/design/notification-preferences.md`.

Mara Chen wrote the design with review input from the Account Settings and Messaging teams. The supporting files are snapshots used for this review, not implementation instructions. Read the product brief first, then the architecture and operating files before comparing the design with the team's writing guide.

The packet describes a small account-level preference store, its API, and its propagation to message delivery. The planned change is still in design and has not been approved for implementation.
