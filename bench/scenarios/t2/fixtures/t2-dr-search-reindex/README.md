# Product search re-index review packet

This packet contains the design and operating context for replacing the product search index without taking the catalog search endpoint offline. The packet was assembled for a design review by the Search Platform team. The design was written by Mira Chen, with operating notes from the Catalog, Reliability, and Finance teams.

The primary document is `docs/design/zero-downtime-reindex.md`. The other files are working documents that a reviewer would normally consult before approving the change. Figures are representative project data, not production credentials or customer data.
