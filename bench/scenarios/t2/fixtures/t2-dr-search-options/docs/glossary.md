# Search glossary

| Term | Meaning |
| --- | --- |
| active product | A product that can be shown in at least one storefront |
| catalogue version | Monotonic version attached to a committed product event |
| prefix query | A title lookup whose term is anchored at the beginning of the indexed title |
| search document | A representation of catalogue fields stored in a search index |
| read target | The database or search index currently serving storefront reads |
| campaign peak | The fifteen-minute traffic period after a marketing launch |
| analyzer | The language-specific process that turns text into searchable terms |
| cutover | The point at which the Catalogue API changes its read target |
