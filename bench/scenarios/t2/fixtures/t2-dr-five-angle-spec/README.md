# Team workspace invite review packet

This packet contains the current design for inviting people to shared workspaces and the small set of service records used to review it. It was assembled for the design review by the Workspace Foundations team: Mira Chen (product), Tomas Ilic (backend), and Jo Alvarez (client). The design was written after the first API prototype and is the version the team considers ready for implementation.

The document under review is `docs/design/team-workspace-invites.md`. Files in `context/` record current service behavior, targets, policies, traffic, and budget figures. They are included so a reviewer can check the design against the systems around it rather than reading the design in isolation.

The packet is self-contained. Names, identifiers, and addresses in examples are fictional.
