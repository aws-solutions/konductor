# UX Research Notes - Feature Usability

**Researcher:** Taylor Kim  
**Date:** May 2025

## Export CSV Feature
### User Testing Findings
- Users want to select which columns to export
- Need preview before downloading large files
- Confusion about "customer ID" vs "user ID"
- **Pain point:** Can't filter by date range in current export

### Design Recommendations
1. Column selector with search
2. Progress indicator for large exports
3. Tooltip explaining data fields
4. Sample export button

## Sales Notes Feature
### User Testing Findings
- Sales reps want rich text (bold, bullet points)
- Need to @mention colleagues in notes
- Mobile access is critical
- **Pain point:** Notes don't sync with CRM

### Design Recommendations  
1. Simple rich text editor (basic formatting)
2. @mention autocomplete
3. Mobile-optimized input
4. CRM sync as phase 2

## Support Tickets Feature
### User Testing Findings
- Support teams want automatic ticket creation
- Need status syncing (open → in progress → resolved)
- Email notifications required
- **Pain point:** Can't attach calendar event to existing ticket

### Design Recommendations
1. One-click ticket creation from event
2. Status badge on calendar
3. Email templates for notifications
4. "Link to existing ticket" option

## Common Themes
- All features need keyboard shortcuts
- Consistency in UI patterns
- Clear success/error messages
- Accessibility requirements (WCAG 2.1 AA)
