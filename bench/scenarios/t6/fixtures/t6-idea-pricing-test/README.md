# OrbitLoom pricing experiment folder

This folder is a working handoff for the OrbitLoom online course platform team. It contains the planning notes, exports, calendars, and analysis materials for the April 2025 pricing-page experiment. Some files are working notes and some are final exports; dates and labels are kept so the team can trace what was known when.

The two page experiences are called Control and Variant B. The primary business metric is a paid annual-plan checkout. Refunds arrive after the initial purchase event, so the exports do not all use the same observation window.

There is no application code in this handoff. Data files are small extracts intended for review in a spreadsheet or a short script.
