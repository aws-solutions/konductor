# Analytics dictionary excerpt

`assigned_pricing_page`: one learner-level assignment record after exclusions.

`checkout_started`: a checkout form opened for the assigned page version.

`annual_paid`: the payment provider returned success for an annual-plan order. This is a gross purchase event and can later be reversed by a refund.

`refund_7d`: an order refunded within seven calendar days of the successful payment. Finance may deliver this after the experiment has ended.

`page_variant`: `A` for the existing page and `B` for the copy test. The marketing system also has a `landing_variant` field; those fields are not interchangeable.
