# Tenant Portal Project - Oakwood Properties

This folder contains project documentation, planning materials, and team information for the Oakwood Properties Tenant Portal MVP.

## Overview
The Tenant Portal project aims to provide a self-service platform for Oakwood Properties' residential tenants. The portal will handle maintenance requests, rent payments, document storage, and communication between tenants and property management.

## File Structure
- `backlog/` - Product backlog and feature definitions
- `team/` - Team information, calendars, and velocity data  
- `contracts/` - Contractual agreements and obligations
- `meetings/` - Meeting notes and planning discussions
- `docs/` - Project documentation and memos

## Current Status
We're in the planning phase for Q1 2025 launch. The team has completed initial discovery and is now working on MVP scope definition and capacity planning.
