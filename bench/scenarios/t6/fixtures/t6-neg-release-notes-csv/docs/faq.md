# Mobile Banking App - Frequently Asked Questions

## General Questions

### What's new in the latest version?
Check our [release notes](release-notes.md) for the most recent changes. We update the app regularly with new features, improvements, and bug fixes.

### How often is the app updated?
We release updates approximately every 2-4 weeks. Major features come in quarterly releases, while security patches and bug fixes are released as needed.

### Is my data secure?
Yes, we use bank-level encryption and follow industry best practices for security. All data is encrypted in transit and at rest.

## Release Notes Questions

### Where can I find old release notes?
All historical release notes are maintained in our documentation. You can find them in the `docs/` folder or contact support for specific versions.

### Why don't release notes include technical details?
We focus on user-facing changes to keep notes accessible. Technical implementation details are documented internally for our engineering team.

### How are release notes organized?
Notes are organized by version, with changes categorized as New Features, Improvements, Bug Fixes, or Security Updates. Each category uses bullet points for clarity.

### What if I find an error in the release notes?
Please contact our support team or submit feedback through the app. We appreciate corrections and will update the documentation promptly.

## Version Compatibility

### Which versions are currently supported?
We support the current version plus the two previous major versions. Older versions may not receive security updates.

### How do I know if I need to update?
The app will notify you when updates are available. We recommend always using the latest version for security and feature access.

### What happens if I don't update?
You may miss new features, performance improvements, and important security patches. Some features may stop working if you're too far behind.

## Feature Questions

### How are new features decided?
Features are prioritized based on user feedback, market research, and strategic goals. You can suggest features through the app's feedback option.

### Why was feature X removed?
If we remove a feature, it will be noted in the release notes with explanation and any migration path. We try to minimize breaking changes.

### Can I opt out of new features?
Some features can be disabled in settings, but core functionality updates apply to all users for consistency and security.

## Technical Questions

### What platforms are supported?
- iOS: Version 15.0 and later
- Android: Version 10.0 and later

### What if I have problems after an update?
1. Check the release notes for known issues
2. Restart the app and your device
3. Contact support with your device and app version information

### How do I report a bug?
Use the "Report a Problem" option in the app settings or email support@mobilebank.example.com with details.

## Documentation Questions

### Are release notes available in other formats?
Currently, release notes are in Markdown format. We're considering PDF exports for enterprise customers.

### Can I get release notes via email?
Yes, you can subscribe to release notifications in your account settings.

### Is there an API for release information?
Not currently, but we're exploring this for our developer portal.

## Policy Questions

### How far back do release notes go?
We maintain complete release notes for the past 3 years, with summaries available for older versions.

### Are beta releases documented?
Beta releases have separate, internal documentation that's shared with testers.

### What about security vulnerability disclosures?
Security updates are documented at a high level without revealing technical details that could be exploited.

## Common Issues and Solutions

### App won't update
- Check your device has enough storage
- Ensure you're connected to Wi-Fi
- Restart your device and try again

### Features missing after update
- Some features roll out gradually
- Check if the feature requires enabling in settings
- Contact support if issue persists

### Release notes unclear
- We're constantly improving our documentation
- Submit feedback through the app
- Check our help center for additional context
