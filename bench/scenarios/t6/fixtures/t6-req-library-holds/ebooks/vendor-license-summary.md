# E-Book Vendor License Summary - DigitalRead Inc.

## Contract Overview
- Vendor: DigitalRead Inc.
- Contract period: January 2024 - December 2026
- Platform: DigitalRead Library Platform (DRLP)
- Content: 85,000+ e-book titles
- Audiobooks: 12,000+ titles (separate license)

## Licensing Models

### 1. One Copy One User (OCOU)
- **Primary model for new releases**
- Each copy can be checked out by one patron at a time
- No waiting lists - first come, first served
- Standard checkout period: 21 days
- Automatic returns at end of period
- Unlimited checkouts per copy

### 2. Metered Access
- For backlist and midlist titles
- Purchased credits for X number of checkouts
- 1 credit = 1 checkout
- Credits expire after 24 months
- No simultaneous use limits

### 3. Simultaneous Use
- **For educational and high-demand titles only**
- Limited to 500 specific titles
- Up to 3 simultaneous users per copy
- Additional fee per simultaneous user slot
- Requires annual renewal

## Hold and Waitlist Provisions

### Current System (Legacy)
- No automated waitlist functionality
- Manual tracking by library staff
- Patrons must re-attempt checkout when item becomes available

### New System Requirements
- **Waitlist integration mandatory for OCOU titles**
- Maximum waitlist length: 25 patrons per title
- Automatic notification when item available
- 48-hour checkout window after notification
- Patron forfeits spot if not checked out within window

## Technical Requirements
- API integration with library ILS (Integrated Library System)
- Real-time availability updates
- Patron authentication via SIP2 or OAuth
- Usage statistics reporting
- DRM: Adobe DRM and Readium LCP supported

## Special Notes
- Children's e-books: Unlimited simultaneous access for educational titles
- Accessibility: Must support screen readers and text-to-speech
- Offline reading: 7-day offline access after download
- Geographic restrictions: Limited to county residents only

## Cost Structure
- Base platform fee: $15,000 annually
- Per-title fees vary by model:
  - OCOU: $25-75 per title
  - Metered: $2-5 per credit
  - Simultaneous: $50-150 per title + $10 per user slot
