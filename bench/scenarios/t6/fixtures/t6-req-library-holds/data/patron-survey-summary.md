# Patron Survey Summary - Holds System Preferences

## Survey Details
- Date conducted: November 2023
- Sample size: 1,247 library card holders
- Response rate: 42%
- Margin of error: ±3%

## Key Findings

### Current Holds Experience
- 78% of patrons currently place holds by phone
- 15% visit branches in person for holds
- 7% use the limited online system (only for e-books)
- Average wait time for phone hold placement: 8 minutes

### Desired Features for New System
1. **Online holds placement** (97% want this)
2. **Email notifications** (92%)
3. **Text message alerts** (85%)
4. **Mobile app access** (78%)
5. **Real-time waitlist position** (74%)
6. **Estimated wait time** (68%)
7. **Multiple pickup branch selection** (65%)
8. **Hold renewal option** (61%)

### Accessibility Preferences
- 23% of respondents prefer larger text interfaces
- 18% use screen readers or other assistive technology
- 12% mentioned color contrast requirements
- 8% need keyboard-only navigation

### Technology Access
- 89% have smartphones
- 76% use library website monthly
- 41% prefer text over email for notifications
- 22% have limited internet access at home

### Demographic Notes
- Senior patrons (65+) prefer email notifications (73%)
- Parents prefer text notifications (68%)
- Students prefer mobile app (82%)
- Patrons with disabilities: 14% of survey population

## Quotes from Patrons
- "I'd use the library more if I could place holds from home."
- "Text alerts would be perfect for when my books are ready."
- "The current phone system is frustrating during busy hours."
- "I hope the new system works with my screen reader."

## Recommendations from Survey Analysis
1. Prioritize web and mobile access
2. Support multiple notification channels
3. Ensure accessibility compliance
4. Consider patrons with limited internet access
5. Provide clear instructions for all age groups
