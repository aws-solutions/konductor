# Library Holds System Project

## Project Status: Planning Phase

This folder contains planning documents for the County Library Service's new online holds and waitlist system for physical books and e-books.

### Background
The county library service currently uses a legacy system for managing holds that was built in 2005. Patrons must call branches or visit in person to place holds. The new system will allow online holds through our website and mobile app, with automated notifications and integrated waitlist management.

### Contents
- **policy/**: Circulation policy excerpts and branch-specific rules
- **data/**: Sample data exports and usage statistics
- **meetings/**: Notes from stakeholder meetings and interviews
- **ebooks/**: Documentation from e-book vendors and license agreements
- **accessibility/**: Accessibility requirements and standards
- **board/**: Board memos and strategic direction documents
