# Harborlight Money onboarding folder

This folder is the working evidence set for the Harborlight Money mobile app. It contains exports, support notes, release notes, product research, and older planning drafts gathered between January and February 2025.

The app lets people create a private spending plan. New accounts can browse a short preview, but they need a verified email before they can save a plan. The team calls the path from account creation through the saved-plan screen “onboarding”.

Files are copied from several working sources, so dates, names, and terminology are not perfectly consistent. CSV exports are snapshots rather than a live dashboard. Some notes are unfinished and include hypotheses that were not checked.

The growth team is considering changes to the first-run experience. Use the dated evidence rather than treating every note or draft as settled fact.
