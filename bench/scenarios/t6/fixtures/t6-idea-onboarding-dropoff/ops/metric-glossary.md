# Metric glossary

**Delivery rate** — delivered messages divided by sent messages.

**Verification completion** — backend-accepted verification tokens divided by messages accepted by the email service. Some old slides use a different denominator, so name it in a readout.

**Onboarding completion** — first saved plan divided by backend-verified accounts.

**Cloudmail** — the provider label used in the operational exports. It is not a product segment or an acquisition source.
