# Parts Distributor Search Project

This folder contains materials related to our search engine initiative for AutoPartsDirect. 

## Contents

- **/data/**: Sample query logs and database extracts
- **/code/**: Current search implementation (Node.js module)
- **/docs/**: Meeting notes, vendor quotes, cost analysis
- **/support/**: Customer support complaints and feedback
- **/analysis/**: Various analysis documents and proposals

## Background

Our e-commerce platform handles ~50k part lookups daily. The current search system is a basic SQL full-text search module that was built 3 years ago. With growth, we're seeing increased support tickets about search failures and customer complaints about not finding parts.

The business team has asked for "a proper search engine" to improve customer experience and reduce support load.
