# BrightRelay handbook excerpt

This excerpt came with the quote and is not a contract.

A sender number can be assigned per program. Delivery status may be `queued`, `sent`, `delivered`, or `failed`. An inbound message is visible only if the account enables replies. The handbook recommends that customers publish their own support contact in message copy.

The examples use a generic opt-out sentence and a generic appointment message. They do not say which words are recognized for this account, how quickly a suppression takes effect, or which staff member should respond.
