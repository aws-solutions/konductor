# MotionSpring clinic reminder working folder

This folder is a working collection for MotionSpring, a three-clinic physiotherapy group. It was assembled from front-desk notes, exports, policy excerpts, and vendor material while the team explored text-message appointment reminders.

The files are not a clean specification. Some are old drafts, some are exports made for a different purpose, and some use different names for the same status. Dates in the exports are local to the clinic unless a timezone column is present.

Start with `booking-process.md`, the clinic directory, the intake and appointment exports, then read the interview and meeting notes. Keep the source files unchanged if you make a separate working document.
