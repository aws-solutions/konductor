# Northstar scheduling workspace

This folder is a working set for the Northstar calendar product. It combines product notes, policy excerpts, exports from staging, and a few customer conversations. Some notes are old or incomplete. Dates in CSVs are copied from different operational systems, so do not assume that every column follows the same convention.

The requested product area is account data handling. The source material is for planning, not a promise to customers. Files under `data/` are sanitized examples from internal staging; files under `docs/` include notes and source extracts.
