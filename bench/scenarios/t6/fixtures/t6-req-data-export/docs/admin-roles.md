# Admin roles page copy

**Owner** can change billing, account settings, integrations, and membership.

**Administrator** can manage users, calendars, rooms, and appointments. Some account settings are hidden from administrators.

**Scheduler** can create and change appointments and availability but cannot manage membership or billing.

**Support agent** is an internal Northstar role. Support agents can view a limited diagnostic panel when a customer has granted a support session. The page does not say who may initiate an account-wide data export or which permission would control it.
