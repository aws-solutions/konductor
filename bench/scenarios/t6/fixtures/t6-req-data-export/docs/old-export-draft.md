# Old export screen draft — do not ship

Choose a date range, then press **Export CSV**. The prototype produced one flat file and emailed a link to the person who clicked the button. It was tested with a small Pro account and did not include integrations or custom fields.

Open questions from 2024-11-12:
- How do we verify an administrator?
- What is the maximum package size?
- How long should links live?
- What does “all data” exclude?

This draft predates the background job service.
