# Export-adjacent operations notes

If a background archive job fails, operators can see the job ID, account ID, worker state, and retry count. Operators should not download customer content while diagnosing a failed job. Escalations go to the privacy on-call rotation.

The activity service records account actions. The event vocabulary for a customer-facing export has not been approved. An incident review should be able to distinguish a request from a successful download.
