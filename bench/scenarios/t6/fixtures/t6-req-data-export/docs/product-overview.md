# Product overview

Northstar is a hosted scheduling service for teams that publish appointment availability and let customers book time. An account can contain people, calendars, appointment records, rooms, custom fields, and connections to outside tools.

The web application has a browser admin console. Jobs that take more than a few seconds run in the background and appear in the activity panel. Email notifications are sent to the account's operational contact. The current console has no customer-facing export wizard.
