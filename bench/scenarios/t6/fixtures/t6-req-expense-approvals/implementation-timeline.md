# Implementation Timeline - Expense Claims System

**Version:** 1.0
**Last updated:** 5 April 2024
**Owner:** James Wilson, Operations Manager

## Phase 1: Preparation (April 2024)

### Week 1-2: Requirements Finalisation
- Review all stakeholder feedback
- Finalise requirements document
- Obtain Board Finance Committee approval
- **Deliverable:** Signed-off requirements v1.0

### Week 3-4: Vendor Selection
- Final demos with shortlisted vendors
- Commercial negotiations
- Contract signing
- **Deliverable:** Signed contract with selected vendor

## Phase 2: Configuration (May-June 2024)

### May: System Setup
- Project kick-off with vendor
- Environment setup (test, UAT, production)
- Basic configuration (users, grants, approval rules)
- **Deliverable:** Configured test environment

### June: Integration & Testing
- Xero integration setup
- HR system data sync
- Unit testing by vendor
- **Deliverable:** Integrated test environment ready for UAT

## Phase 3: User Acceptance (July 2024)

### Week 1-2: UAT Preparation
- Select UAT group (10 staff across departments)
- Prepare test scenarios
- Training materials development
- **Deliverable:** UAT plan and test cases

### Week 3-4: UAT Execution
- UAT group testing
- Bug fixing and refinement
- Feedback incorporation
- **Deliverable:** UAT sign-off

## Phase 4: Go-Live (August-September 2024)

### August: Preparation
- Final system configuration
- Data migration (staff, grants, rates)
- Training all staff (45 people)
- Communication plan execution
- **Deliverable:** Production-ready system

### September: Parallel Running
- Old and new systems run side-by-side
- Monitor performance and issues
- Refine processes based on feedback
- **Deliverable:** Parallel run report

## Phase 5: Live Operation (October 2024 onwards)

### October: Go-Live
- Switch off old email process
- New system live for all claims
- Support desk active
- **Deliverable:** System live, old process retired

### November: Post-Implementation Review
- Measure against success criteria
- Identify improvements
- Plan enhancements
- **Deliverable:** Post-implementation review report

## Key Milestones

1. **15 April:** Requirements finalised
2. **31 May:** Vendor selected and contracted
3. **30 June:** System configured and integrated
4. **31 July:** UAT completed and signed off
5. **30 September:** Parallel running completed
6. **15 October:** Full go-live

## Critical Success Factors

- Executive sponsorship (Helen Roberts)
- Finance team engagement (Sarah, Mark)
- Staff involvement in UAT
- Clear communication throughout
- Adequate training for all users

## Risks and Mitigations

- **Vendor delays:** Weekly progress reviews, penalty clauses
- **Staff resistance:** Early communication, involvement in UAT
- **Integration issues:** Technical workshops, contingency time
- **Budget overrun:** Regular financial tracking, change control

- **Vendor team:** Project manager, config specialist, technical lead
- **UAT group:** 10 staff across departments
- **Training:** All 45 staff (2 sessions each)
