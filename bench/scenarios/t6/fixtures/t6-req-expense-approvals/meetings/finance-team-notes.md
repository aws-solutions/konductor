# Finance Team Meeting - System Requirements

**Date:** 28 March 2024
**Attendees:** Sarah, Mark, Finance Assistants (2)
**Topic:** What we need from the new expense system

## Pain Points with Current Process

1. **Manual data entry** - typing from PDFs into Xero
2. **Chasing approvers** - don't know who has the claim
3. **Grant coding errors** - have to manually check each one
4. **Missing information** - forms incomplete, chase staff
5. **Payment timing** - claims come in randomly, hard to batch
6. **Audit trail** - hard to prove who approved what

## Must-Have Features

### Approval Workflow
- Automatic routing based on amount
- Escalation if no response in 2 days
- Delegation when approvers away
- Secondary approver for large amounts

### Grant Compliance
- Validate grant code exists
- Check against restriction rules
- Flag potential violations
- Prevent submission if violation

### Receipt Management
- Digital upload (photo/scan)
- OCR to extract data
- Link to claim automatically
- Store for 7+ years

### Integration
- Push approved claims to Xero
- Pull staff list from HR system
- Sync with grant database
- Export for audit

### Reporting
- Real-time dashboard
- Ageing report (claims outstanding)
- Grant spending analysis
- Approval times tracking

## Nice-to-Have

- Budget checking before approval
- Mileage calculator with map
- Per diem calculator
- Mobile receipt capture
- Policy reminders during submission
- Bulk approval for small claims

## Technical Requirements

- Cloud-based (no on-premise)
- UK data hosting (GDPR)
- API access for integration
- Role-based permissions
- Audit log of all changes
- Backup and recovery

## Success Criteria for Finance

1. Reduce manual entry by 90%
2. Eliminate grant coding errors
3. Process 95% of claims within 5 days
4. Complete audit trail for every claim
5. Reduce finance time on expenses from 15 to 3 hours/week
