# Meeting Notes: Expense Claims Process Review

**Date:** 20 March 2024
**Time:** 10:00-11:30
**Location:** Board Room
**Attendees:** Sarah Chen (Finance), James Wilson (Operations), Priya Patel (Programmes), Mark Taylor (Finance)
**Facilitator:** Sarah Chen

## Purpose

Discuss pain points in current expense claim process and identify requirements for new system.

## Current Process Issues

1. **Delays:** Average 14 days from submission to payment. Longest case: 42 days.
2. **Errors:** Frequent coding mistakes (grant restrictions not checked).
3. **Visibility:** No one knows where a claim is in the process.
4. **Manual work:** Finance team spends ~15 hours/week manually entering data from PDFs.

## Requirements Discussed

### Must Have
- Electronic submission (no more emailing PDFs)
- Automated routing to approvers
- Receipt attachment/upload
- Grant code validation against restrictions
- Approval workflow with escalations
- Real-time status tracking
- Integration with Xero (our accounting software)
- Mobile-friendly interface for field staff

### Should Have
- Mileage calculator
- Per diem rates by location
- Budget checking before approval
- Reporting dashboard
- Bulk approval for small claims

### Could Have
- OCR for receipt scanning
- Policy reminders during submission
- Automated compliance checks
- Integration with travel booking system

### Won't Have (this phase)
- Corporate credit cards
- Advanced analytics
- Multi-currency support

## Key Decisions

1. **Approval workflow:** Need to handle absences (holidays, sick leave). Current process breaks when approver is away.
2. **Thresholds:** Need to review current £500/£2,000 limits. Some large project expenses need faster approval.
3. **Receipts:** Should we require photos for all claims? Currently only over certain amounts.
4. **Grant restrictions:** Complex - some grants allow travel but not accommodation, some have daily rate caps.
