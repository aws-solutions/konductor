# BrightHope Charity - Expense Claims Modernisation

This folder contains materials for the expense claims system replacement project. We're moving from the current emailed spreadsheet process to a proper digital system.

## Contents

- **handbook/**: Excerpts from the Finance Handbook
- **data/**: Sample data from last year's claims (anonymised)
- **meetings/**: Notes from stakeholder discussions
- **audit/**: Audit findings and correspondence
- **vendors/**: Vendor feature lists and proposals
- **org-chart.pdf**: Current organisational structure
- **grants-list.xlsx**: Active grants and their restrictions
- **current-claim-form.pdf**: The existing expense claim form
- **project-brief.md**: Initial project scope

## Background

BrightHope Charity supports community development projects in three regions. We have 45 staff members and an annual budget of £2.8M. The current expense claim process involves staff emailing filled PDF forms to their line managers, who forward them to finance. This creates delays, errors, and poor visibility.

The Board approved £85,000 for a new system in the 2024 budget.
