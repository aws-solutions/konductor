# Shift handoff note

2025-02-03, written by depot coordinator Leni Ward.

The tablet cupboard is beside the route board. Crews currently write a short mark on the board when taking a device and wipe the screen at return. The mark is sometimes unreadable, especially when a late crew takes over from a morning crew.

The device label is visible on the back. A replacement tablet can be issued when a battery or screen problem is reported. There is no shared checklist for checking that unsent work has left the device before it changes hands.

Leni asked whether the new app should show the last worker and whether a worker can sign in with a personal account. She has not received an answer.
