# Asset register cleanup notes

2025-01-28, Asset Control.

The export contains both current and retired tags. Tags beginning with “TMP” are temporary labels used during construction and should not be offered as a normal route choice. Some sites have a leading zero in the printed tag but not in the legacy export.

When a site has two assets of the same type, the access point distinguishes them. Asset Control owns corrections to the catalog. The inspection app may cache a route list but must not create a new asset silently.
