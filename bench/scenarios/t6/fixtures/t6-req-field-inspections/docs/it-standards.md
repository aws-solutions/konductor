# IT standards page: managed field tablets

Issued by End User Computing, 2025-01-06.

The supported field device is a managed rugged Android tablet running Android 13 or later. The standard screen is 8 inches. The device has a rear camera, GPS, cellular data, and depot Wi-Fi. Devices are enrolled in the utility MDM and receive application updates through the managed catalogue.

The app must support the standard managed browser for account recovery and must not require administrator access. Local app data is subject to the MDM wipe process. The device clock is managed by the operating system; an app must not allow an inspector to set a separate clock.

IT has not selected a tablet model for a purchase refresh. The Android version and management controls are the current compatibility boundary.
