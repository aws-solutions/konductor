# Asset type catalog

The asset register uses these current categories:

| Code | Display name | Typical check |
| --- | --- | --- |
| PS | Pump station | pump, alarm panel, housekeeping |
| IN | Intake screen | screen condition, debris, approach |
| RV | Reservoir valve | valve position, chamber, leak signs |
| CL | Chlorination cabinet | cabinet, labels, dosing equipment |
| HY | Hydrant | cap, visibility, seepage |
| MG | Flow meter | display, seal, reading |

The same site can have several assets and each asset has its own tag. Retired tags remain in exports for audit history. The catalog is maintained by Asset Control, not by the field crew.
