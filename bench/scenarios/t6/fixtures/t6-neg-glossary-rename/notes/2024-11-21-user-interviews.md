# User interviews — 21 Nov 2024

Interviewer: Sol Kim
Participants: Jules (freelance editor), Ren (small agency), Bea (student)

Jules calls the shared container a folder even after seeing the Workspace label. Ren understands Workspace but says the member screen feels like an admin console. Bea only used a personal Workspace and did not notice the invite button.

Quotes, lightly cleaned:

- “I want to write first and sort later.”
- “The note is the thing I trust. The container name is secondary.”
- “I thought archive meant gone.”
