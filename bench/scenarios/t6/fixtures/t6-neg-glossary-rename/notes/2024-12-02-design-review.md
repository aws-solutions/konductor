# Design review — 2 Dec 2024

The compact note list is easier to scan at 320px, although the selected state is too faint. The team liked the new member chip but could not agree on whether roles should appear before names.

Open questions:

- Do we keep the archive icon in the top bar?
- Should a shared Workspace show its owner on the empty state?
- Can the first note prompt be dismissed for a week?

Decision recorded elsewhere: keyboard focus must remain visible after closing the command palette.
