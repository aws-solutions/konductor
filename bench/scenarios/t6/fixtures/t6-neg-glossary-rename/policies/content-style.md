# Content style excerpt

Use concrete verbs and short headings. Explain a product term the first time it appears in a page, then use the same spelling consistently. Avoid jokes in error messages and do not promise a date that product has not committed to.

Customer-facing copy uses sentence case. Button labels use the shortest phrase that still tells a person what will happen. When a term has a technical meaning and a display meaning, document the difference for support and engineering.

This excerpt is a reminder, not a complete editorial policy.
