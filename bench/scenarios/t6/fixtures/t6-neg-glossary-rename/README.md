# Pinboard product folder

This folder holds working product material for Pinboard, a small note-taking app used by teams and solo researchers. It mixes current documents with meeting notes, exports, policy excerpts, and a few drafts that have not been cleaned up.

The `docs/` folder contains the documents people usually consult first. Files under `notes/` are informal records, while `data/` contains small exports used in planning. Dates in older files are retained because they explain why a decision was made.

This is a local snapshot for the product group. It is intentionally untidy: do not assume that every sentence in an old draft still describes the shipped app.
