# Product requirements draft v0.7

This older draft predates the current member permissions work. It uses a few provisional terms and should not be treated as the source for current UI copy.

The home screen opens into a Workspace. A person can add notes, pin a note, and invite another person. The first-use prompt should be skippable, and the search index should be ready before the first note appears.

Open issues from the draft: offline conflict copy, account deletion timing, and whether a Workspace can be transferred by a non-owner. The estimates in the margin were removed from this copy.
