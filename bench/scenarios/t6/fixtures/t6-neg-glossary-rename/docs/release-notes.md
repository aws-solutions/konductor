# Release notes

## 2.8.0 — 2024-12-12

- Added keyboard navigation to the note list.
- Reduced the time to open a large Workspace on slower laptops.
- Added a warning before removing the last member from a shared Workspace.

- Fixed an export that omitted tags containing a slash.
- Fixed a blank state that appeared after returning from search.
- Updated the help link in the Workspace member dialog.

## 2.7.0 — 2024-11-05

- Added note backlinks.
- Added a compact view for narrow screens.
