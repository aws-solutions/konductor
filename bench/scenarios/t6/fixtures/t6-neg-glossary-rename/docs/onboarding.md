# First-run copy

## Welcome

Keep the ideas that matter. Start a Workspace for a class, a client, or the messy project you have been postponing.

## Create your first Workspace

Give it a name that makes sense to the people you may invite. You can change the name later. Add one note before leaving this screen so the empty state does not feel like a dead end.

## Invite a teammate

When your first note is useful to someone else, open Members and send an invite. People can read shared notes without learning every setting on day one.
