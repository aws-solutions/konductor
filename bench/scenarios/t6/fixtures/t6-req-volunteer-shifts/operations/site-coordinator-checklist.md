# Site Coordinator Daily Checklist

## Before Shift
- [ ] Review volunteer roster for today
- [ ] Check for any special needs or accommodations
- [ ] Confirm emergency contact info is accessible
- [ ] Check first aid kit supplies
- [ ] Review weather forecast
- [ ] Set up sign-in station
- [ ] Prepare materials/tools for today's work
- [ ] Check site safety (clear walkways, etc.)

## During Shift
- [ ] Greet volunteers upon arrival
- [ ] Conduct brief orientation for new volunteers
- [ ] Assign roles and responsibilities
- [ ] Monitor safety compliance
- [ ] Track attendance (sign-in sheet)
- [ ] Address any issues or concerns
- [ ] Ensure breaks are taken
- [ ] Maintain communication with main office

## After Shift
- [ ] Thank volunteers
- [ ] Collect sign-in sheet
- [ ] Record hours worked
- [ ] Note any incidents or issues
- [ ] Clean up work area
- [ ] Secure site (lock doors, etc.)
- [ ] Report to Volunteer Coordinator
- [ ] Schedule follow-up if needed

## Weekly Tasks
- [ ] Review upcoming shifts
- [ ] Check volunteer availability
- [ ] Order supplies if needed
- [ ] Attend coordinator meeting (bi-weekly)
- [ ] Submit hours report
- [ ] Plan for special events

## Monthly Tasks
- [ ] Review safety equipment
- [ ] Update emergency contact list
- [ ] Evaluate volunteer performance
- [ ] Attend training session
- [ ] Submit site maintenance requests

## Notes for New System

### Data Access Needed
- Today's volunteer list with contact info
- Emergency contacts for today's volunteers
- Volunteer skills/qualifications
- Any special notes or accommodations

### Data Access NOT Needed
- (to be agreed with the board; see coordinator notes)

### Communication Needs
- Quick way to contact today's volunteers
- Emergency notification system
- Shift change/cancellation alerts
- Volunteer feedback collection

### Reporting Needs
- Attendance tracking
- Hours worked
- Incident reports
- Supply usage
- Volunteer feedback

## Reminders
- Always have phone charged and accessible
- Know location of emergency exits and equipment
- Document any issues immediately
- Follow safeguarding procedures at all times
- Maintain professional boundaries with volunteers
- Report concerns to Volunteer Coordinator promptly

**Remember:** Your primary responsibility is volunteer safety and wellbeing.
