# Project Kickoff: Digital Volunteer Sign-up System
**Date:** February 10, 2024
**Attendees:** Sarah J (Volunteer Coordinator), Miguel R (Ops), Tom W (IT), Alisha C (Board)

## Agenda
1. Current system pain points
2. Requirements gathering
3. Timeline and budget
4. Next steps

## Notes

### Current System Issues
- Spreadsheet getting unwieldy (300+ volunteers)
- Double-booking happens when multiple people edit
- No automated reminders
- Manual background check tracking
- Can't enforce shift caps automatically
- Time zones confusing for remote volunteers

### Requirements Discussed
**Must have:**
- Secure sign-up system accessible to volunteers
- Automated shift reminders
- Background check status tracking
- Shift caps enforcement
- Cancellation tracking

**Should have:**
- Group booking functionality
- Multi-language support (Spanish at minimum)
- Mobile-friendly interface
- Reporting for coordinators

**Nice to have:**
- Integration with training system
- Volunteer performance tracking
- Donation tracking

### Questions Raised
1. How do we handle volunteers under 18? Parent consent forms?
2. What data should coordinators see vs. not see? (Sarah: "Coordinators shouldn't see age or medical info")
3. How to handle different time zones? Some volunteers sign up from other states.
4. Group bookings - minimum size? Advance notice?
5. Driver roles - DMV check frequency?

### Next Steps
- Sarah to draft initial requirements document
- Tom to research vendor options
- Miguel to analyze shift patterns from current data
- Alisha to review safeguarding implications
