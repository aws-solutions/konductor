# Pinboard glossary

This is the short list of terms used by the product, support, and customer education teams. The JSON block is the structured copy used by the documentation checks.

## Project: notes

A Project is a shared space where a team keeps notes, notebooks, and members for one body of work. A Project can be personal or shared, and its owner controls who can join.

Use **Project** when referring to the product container. Do not use "team folder" in customer-facing copy.
