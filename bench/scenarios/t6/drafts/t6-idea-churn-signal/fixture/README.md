# PantryPilot planning folder

This is a working folder for PantryPilot, a small subscription meal-kit company. It contains notes, exports, policy excerpts, and old experiment material used by product, support, and finance.

The exports are snapshots rather than a clean warehouse table. Dates are in local Pacific time unless a file says otherwise. Subscriber IDs are internal test values. Some notes are informal and may have been written before the latest dashboard refresh.

Start with the founder request, then use the source exports to check claims. The product team keeps older drafts in `experiments/` so that decisions can be traced.
