# Export field notes

`appointment_local` is a displayed local date and time. `timezone` came from a later export revision and may be blank in older files. `status` values seen in the last quarter include booked, cancelled, completed, and no_show.

`consent` is a yes/no field in the appointment export. A blank means unknown, not approval. `language` is free text in one export and a controlled value in another. `mobile` can be blank, malformed, or a shared number.

These notes describe fields, not a data-quality signoff.
