# Internal price sheet notes

Use the 730-hour month in the JSON sheet. On-demand billing charges the average monthly read and write request volume. Provisioned capacity charges the steady schedule and the 30-hour launch schedule; autoscaling is represented by the two capacity windows in the sheet. The relational estimate charges each cluster node for the full month.

All options also carry 100 GB of table or database storage and 200 GB of backups. Storage and backup charges use the common rates in the sheet. These figures are planning estimates in USD and exclude application compute, network transfer, and engineering labor.
