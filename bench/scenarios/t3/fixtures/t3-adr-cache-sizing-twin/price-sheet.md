# Monthly node price sheet

The finance export below is the price source for this review. Prices are recurring monthly on-demand estimates in USD for one cache node. They include the memory tier and standard network allowance. Storage snapshots and the unchanged client service are outside this comparison.

| Price-sheet id | Memory | Monthly price |
| --- | ---: | ---: |
| `cache-52` | 52 GB | 420 USD |
| `cache-105` | 105 GB | 650 USD |
| `cache-209` | 209 GB | 1,400 USD |

Use the JSON export for arithmetic so the displayed table and the billing data have a single value per tier.
