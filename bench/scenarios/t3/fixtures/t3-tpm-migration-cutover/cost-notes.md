# Recurring cost notes

The target cluster charge continues after the move because it becomes the serving cluster. Replication and observability are recurring services; migration support covers the planned change window and is billed monthly for the migration period. Snapshot storage is the lower-complexity copy option's retained staging allocation. The dual-write runtime is a separate application-side service charge.

The finance sheet sets the migration program's recurring ceiling at 5,000 USD per month. One-time implementation labor is outside this ceiling, so it must not be added to the monthly comparison.
