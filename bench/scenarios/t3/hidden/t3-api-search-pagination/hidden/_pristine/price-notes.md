# Search service price notes

The attached price sheet is the vendor quote for one production deployment. A month is billed as 30 days and request charges use the sustained peak rate in `traffic.csv` as a conservative planning proxy. Storage and replica charges are monthly, while the fixed line item includes the quoted control-plane and indexing charge.

The quote does not include an additional fee for a continuation value. It does include enough storage for the option's stated replica count. Round the resulting monthly estimate to cents for the architecture record. These are planning prices, not an invoice or a commitment.
