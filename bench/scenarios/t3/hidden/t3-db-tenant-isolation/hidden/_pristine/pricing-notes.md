# Finance worksheet notes

Finance bills retained storage at 0.12 USD per decimal gigabyte-month. The row-size estimate already includes the table payload and its indexes, so the data-shape export must not be indexed a second time. Shared capacity is billed per compute unit-month. Request processing is billed per million API requests. A deployment with one database file per customer also incurs the small database-file control-plane charge for every file.

The monthly infrastructure ceiling for this service is 600 USD. The ceiling excludes staff time and customer-specific add-ons.
