# AGENTS.md

Guidance for AI coding assistants working in this repository. `tinydates` is a small Node package that parses and formats ISO dates. It has no runtime dependencies.

## Commands

- Run the tests: `npm test` (this runs `node --test`).
- Run the linter: `npm run lint`. It must pass before you finish.
- Regenerate `dist/`: `npm run release`.

`README.md` still mentions `yarn install`, `yarn test` and `yarn build`. That is out of date. The package defines only the npm scripts `test`, `lint` and `release`; there is no build script.

## Code style

- 2-space indent, single quotes, semicolons (see `.editorconfig` and `CONTRIBUTING.md`).
- Named exports only (`exports.name = name`). Do not use default exports; the linter rejects them.
- Node 20 or later (`engines` in `package.json`).
- Do not add runtime dependencies. If you think one is needed, say so and ask first.

## Tests

- Tests sit next to the code they cover, named `*.test.js`, and use `node:test` with `node:assert/strict`.
- Add or update a test for every behavior change in `src/`.

## Files you must not edit by hand

- `dist/` is generated by `scripts/release.js`. Change the sources in `src/` and run `npm run release`.

## Commits

Use Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:` followed by a short summary, for example `fix: reject dates with extra text`.
