# User stories, boiled down for design

| Story | Need | Design consequence |
|-------|------|--------------------|
| US-1 | Search the catalog on a phone | A public read path with availability and a mobile layout |
| US-2 | Check out in under 2 minutes | Kiosk flow: scan card, scan tool, show due date |
| US-3 | Reserve for the next day | Reservations (window conflicts with REQ-6) |
| US-4 | Kiosk works offline for 8 hours | Local store on the kiosk and a sync queue |
| US-5 | Reminder the day before | A daily job that calls the SMS provider |
| US-6 | Manage the catalog | Staff screens; changes visible within a minute |
| US-7 | Delete my data | Identity data kept apart from loan records |
| US-8 | Pay a late fee at the desk | Staff record a payment; the block clears |
