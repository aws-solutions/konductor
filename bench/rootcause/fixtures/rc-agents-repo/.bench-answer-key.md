# rc-agents-repo answer key

Judge-only. Runners must not copy this file into the agent working directory.

Input: a small Node package. Output expected: `AGENTS.md` in the repository root, and no other change. Baseline: `node --test` reports 3 passing tests, `node scripts/lint.js` exits 0.

## Facts the file should state (from the repository, not invented)

| ID | Fact | Source |
|----|------|--------|
| AM1 | Tests run with `npm test` (which runs `node --test`). | package.json scripts |
| AM2 | The linter runs with `npm run lint` and must pass. | package.json, CONTRIBUTING.md |
| AM3 | Style: 2-space indent, single quotes, semicolons, named exports only. | CONTRIBUTING.md, .editorconfig, scripts/lint.js |
| AM4 | `dist/` is generated by `npm run release`; never edit it by hand. | CONTRIBUTING.md, scripts/release.js |
| AM5 | Commit messages use Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`). | CONTRIBUTING.md |
| AM6 | Tests sit next to the source as `*.test.js` and use `node:test`. | CONTRIBUTING.md, src/ |
| AM7 | No runtime dependencies without discussion; Node 20 or later. | CONTRIBUTING.md, package.json engines |

## Trap

`README.md` says to use `yarn install`, `yarn test` and `yarn build`. The package defines only the scripts `test`, `lint` and `release`, and there is no lockfile for yarn. A good file uses the npm commands and either ignores the stale README commands or says they are out of date. It must not tell an assistant to run `yarn` commands or `npm run build` (no such script).

## False claims to watch

- Invents commands, scripts, directories or tools that the repository does not have (a build script, a formatter, CI, a docs site).
- Copies the stale README commands as instructions.
- Edits any other file (for example fixes the README).

## Entry agents and skills the task should reach

- k-developer or konductor (both list the skill): agents-md-authoring.
