# Contributing

- Code style: 2-space indent, single quotes, semicolons. Use named exports only (no `module.exports = fn` default export).
- Tests sit next to the code they cover and are named `*.test.js`. They use `node:test`.
- The package has no runtime dependencies. Do not add one without discussing it in an issue.
- `dist/` is generated by the release script. Never edit it by hand.
- Commit messages follow Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`.
- The linter must pass before you open a pull request.
