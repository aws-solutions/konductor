# rc-legacy-table answer key

Judge-only. Runners must not copy this file into the agent working directory.

Input: `docs/legacy-estimates.md`, seven backlog rows with all-human estimates in person-days. Output expected: `docs/agentic-estimates.md`, an estimate for the same backlog with AI coding assistants and agents in the workflow. No change to the input. There is no test command.

## Method behind the numbers

Each item is split into authoring work that AI compresses and work that it does not (requirements, review, integration, verification, security judgment). The tier of an item comes from its description: patterned authoring (CRUD, boilerplate, scaffolding, migration) compresses most; clear intent with novel integration (webhook, API) compresses little; novel architecture, security and failover compress least and can cost more than the legacy value because of the added verification. The result is a range, not a point, and a roll-up with the change against the legacy total.

Reference mid values from the conversion script of the skill (rounded): E-1 5.8 (range 5.0 to 6.7), E-2 4.6 (4.0 to 5.3), E-3 11.1 (10.5 to 11.8), E-4 22.7 (22.0 to 23.5), E-5 3.5 (2.6 to 4.4). Total of the five rows: legacy 56, mid 47.7, about 15 percent lower.

## Seeded points

| ID | What a good answer does |
|----|-------------------------|
| ES1 | E-1 and E-2 (patterned authoring) drop the most: the mid is between 3 and 8 person-days for E-1 and between 2.5 and 6.5 for E-2. |
| ES2 | E-3 (integration) drops little: the mid is between 8 and 13 person-days. |
| ES3 | E-4 (novel architecture and security) does not shrink: the mid is at least 17 person-days and the answer says why (little compressible content, more verification). A blanket discount of 30 to 50 percent fails here. |
| ES4 | E-5 (migration) drops like the first group: the mid is between 2.2 and 4.8 person-days. |
| ES5 | Different tiers get different treatment. One discount percentage applied to every row is the anti-pattern the answer must avoid. |
| ES6 | Every converted row has a low, a mid and a high value in order, and a reason (tier or the kind of work). |
| ES7 | The roll-up states the legacy total of the converted rows (56) and an agentic total in the range 38 to 54, with the change in percent. |
| ES8 | E-6 ("about two weeks") is not converted as if it were a number. The answer flags it, asks for a number or states the assumption it used and excludes it from the total, or shows it apart. |
| ES9 | E-7 has no description. The answer flags it and does not invent a task or a tier. |
| ES10 | Says that the savings come from the authoring part and that review and verification time does not shrink, and that the factors should be calibrated against the team's own history. |

## False claims to watch

- One flat percentage for the whole backlog.
- Reports a converted number for E-7 as if it knew the task.
- Totals that include E-6 or E-7 without saying so, or a total that does not match the rows.
- Treats the estimates as story points or calendar weeks.
