## Reference least-privilege policy (IAM-1 to IAM-4)

The replacement policy must: (IAM-1) be valid JSON with a Statement list; (IAM-2) contain no `iam:` action and no `s3:*`, no `*` action; (IAM-3) allow read actions on the Orders table (GetItem, Query or BatchGetItem) and `s3:GetObject`; (IAM-4) allow no write or delete action and no `Resource: "*"` on S3 or DynamoDB actions. `Scan` is acceptable only if the review says why.

## False claims to watch

- Says the stack already encrypts data, enables point-in-time recovery, or uses a secret store.
- Reports the function role as scoped, or says the bucket is private.
- Adds findings about resources that are not in the template (a VPC, a KMS key, a CloudFront distribution) as if they existed.
- Changes `template.yaml` or `policies/support-role.json` in place.
