# rc-program-tracker answer key

Judge-only. Runners must not copy this file into the agent working directory.

Input: `docs/tracker.md`, `docs/last-status.md`, `docs/risk-log.md`, `docs/budget.md` (report date 2025-03-14). Output expected: `status/status-report.md` and `status/risk-register.md`. Inputs unchanged. There is no code.

## Facts to derive

- Critical path: W3 payment integration (due 2025-02-28, 35 percent) then W7 security review (10 working days) then W9 launch readiness. At the stated pace W3 ends about 2025-04-11, the review ends about 2025-04-25, so the 2025-04-15 launch is missed by 2 to 3 weeks unless scope or dates change.
- Budget: 936,000 spent of 1,200,000 (78 percent) at 55 percent progress. Estimate at completion is about 936,000 / 0.55 = 1.70 million, about 500,000 (42 percent) over budget. Open purchase orders (90,000) add to commitments.

## False claims to watch

- Reports the budget as on plan or the load test as a valid result without comment.
- Invents numbers that are not derivable (a different spend, a new launch date presented as agreed).
- Reports R2 as still open, or leaves R3 without an owner.
- Presents the proposed new launch date as approved.
