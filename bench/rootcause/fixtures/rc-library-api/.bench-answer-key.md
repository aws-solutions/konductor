# rc-library-api answer key

Judge-only. Runners must not copy this file into the agent working directory.

Input: `docs/api-requirements.md`. Output expected: `model/main.smithy` (a Smithy 2.0 model) and `docs/api-notes.md`. No server code, no change to the input. There is no Smithy toolchain in the bench, so checks read the text of the model.

## Seeded model points

| ID | Requirement | What a good model does |
|----|-------------|------------------------|
| SM1 | Books lifecycle | A `Book` resource with an identifier and create, read, update, delete and list bound to it (a `Loan` resource for loans). |
| SM2 | Paged lists (2 million books, loans list) | `@paginated` on ListBooks and ListLoans with a token and a page size member. |
| SM3 | Retried borrow must not double lend | CreateLoan carries a client token member (`@idempotencyToken`) or is documented and marked idempotent. |
| SM4 | Error contract | Client error structures with `@error("client")` and `@httpError` 400, 404, 409 and 429, listed on the operations or the service. |
| SM5 | Field limits | `@length` on title and authors, `@pattern` on ISBN (13 digits), `@range` on copies, `@required` on the mandatory members. |
| SM6 | Reading changes nothing | `@readonly` on Get and List operations. |
| SM7 | HTTP mapping | `@http` with method, URI and code (201 for creates, 204 for delete), and `@httpLabel` for path members. |
| SM8 | Bearer token on everything | `@httpBearerAuth` on the service (and `@auth`). |
| SM9 | Gaps in the requirements | `docs/api-notes.md` lists open questions or assumptions. The renewal rule (twice, 14 days) has no operation or data in the list of operations, so it must be raised or modeled with a stated assumption. Others: the author filter's matching rule, whether members see only their own loans (who is the caller), what the due date is for a new loan, page size limits. |

## Quality checks

- Braces and brackets balance; every operation named in a resource or service is declared; every error named on an operation is declared as a structure.
- At least 8 operations (5 book, create, get, return and list loans) are declared.

## False claims to watch

- Notes say the model was compiled or validated by the Smithy tool (nothing was run).
- Claims renewals are modeled when no renewal operation or member exists.
- Gives an operation a body on a GET or a DELETE.

## Entry agent and skills the task should reach

- k-architect: smithy-modeling (primary), smithy-validation (a self-review of the model before finishing).
