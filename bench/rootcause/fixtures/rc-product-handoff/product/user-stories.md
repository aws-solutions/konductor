# User stories

## US-1: Find a tool
As a member, I want to search the catalog by name or category, so that I know whether a tool is on the shelf before I walk over.
Acceptance: results show available and lent-out tools; the page works on a phone.

## US-2: Check out at the kiosk
As a member, I want to check out a tool in under 2 minutes, so that Saturday lines stay short.
Acceptance: scan the member card, scan the tool label, see the due date.

## US-3: Reserve a tool
As a member, I want to reserve a tool for the next day, so that it is waiting for me.
Acceptance: I can reserve one tool for pickup the next day; I get a confirmation.

## US-4: Keep working when the network is down
As a volunteer on the desk, I want the kiosk to keep checking tools out when the internet is down, so that a bad connection does not stop the library.
Acceptance: the kiosk works for at least 8 hours without a connection and sends its loans when the connection returns.

## US-5: Remind me
As a member, I want a text message the day before a tool is due, so that I do not pay a late fee.
Acceptance: one message per loan, sent the day before the due date in the morning.

## US-6: Manage the catalog
As a staff member, I want to add a tool, retire a tool and flag a tool for repair, so that the catalog is true.
Acceptance: changes show in the member search within a minute.

## US-7: Delete my data
As a member, I want my personal data deleted when I ask, so that I stay in control.
Acceptance: staff can start a deletion request; data is gone within 30 days; loan history is kept without my name.

## US-8: Pay a late fee
As a member, I want to pay a late fee at the desk, so that I can borrow again.
Acceptance: staff record the payment; the member can borrow again once the fee is cleared.
