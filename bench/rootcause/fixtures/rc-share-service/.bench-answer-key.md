# rc-share-service answer key

Judge-only. Runners must not copy this file into the agent working directory.

Input: `docs/architecture.md` (8 components, 7 flows). Output expected: `docs/threat-model.md`. The architecture document stays unchanged. No code.

## Seeded threats

| ID | STRIDE | Source in the description | What a good model says |
|----|--------|---------------------------|------------------------|
| TM1 | Information disclosure, Spoofing | Flow 3: a 6-character token from 36 symbols (about 2 billion values) | Links can be guessed or enumerated; with no limit on requests an attacker finds live links. Use a random token of at least 128 bits and rate-limit link lookups. |
| TM2 | Tampering, Elevation | Flow 2: downloadable before the scan, infected files deleted after minutes | Malware is served during the scan window. Quarantine until clean, serve only scanned files. |
| TM3 | Information disclosure | Flow 3 default expiry never; flow 4 pre-signed URL valid 24 hours | Links live forever by default and the 24-hour download URL can be forwarded or logged. Default expiry, shorter URLs, revocation. |
| TM4 | Repudiation | Flow 7: downloads and admin actions are not logged | No record of who downloaded a file or what an admin deleted. Add an audit log for downloads (time, link, requester address) and admin actions. |
| TM5 | Denial of service, Information disclosure | Flow 4 no limit on password attempts; flow 2 no upload size limit | A short password can be brute-forced; unlimited uploads can fill storage and cost money. Add attempt limits or lockout, a size cap and a quota. |
| TM6 | Elevation of privilege | Flow 6: the menu is hidden for non-admins; the API requires only a valid session | Any signed-in user can call the admin endpoints. Enforce the role on the server for every admin endpoint. |
| TM7 | Information disclosure | Flow 5: link and file name in an email, TLS only when supported | Email travels and sits in inboxes; the file name and link leak, and mail may cross the network in clear text. Require TLS, send less, expire links. |
| TM8 | Information disclosure | Flow 3: unsalted SHA-1 hashes of 4-character-minimum passwords | Hashes can be cracked offline after a database leak. Use a slow salted hash (argon2, bcrypt, scrypt) and a longer minimum. |
| TM9 | Spoofing, Tampering | Flow 1: session cookie for 30 days | No cookie attributes (HttpOnly, Secure, SameSite) or CSRF defense are described; a stolen cookie works for 30 days. |

## Completeness

A good model lists the assets (files, link tokens, passwords, user records, admin capability), draws at least three trust boundaries (browser to API, API to object store and database, scan worker and mailer, identity provider) and covers every one of the 8 components. Each threat carries a likelihood, an impact and a mitigation.

## False claims to watch

- Says the system already rate-limits, scans before download, logs downloads, checks the admin role on the server or salts passwords.
- Invents components (a CDN, a web application firewall, a key management service).
- Rates TM1, TM2 or TM6 as low.
