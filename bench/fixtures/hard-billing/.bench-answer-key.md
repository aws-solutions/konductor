## Seeded problems in the code

- `src/billing/rules.js` holds a mix of both documents (14, 14, half-even, 25, exclusive, 15, end of period, 500) under a comment that
  says the values were copied from the requirements (wrong).
- `src/billing/planchange.js` has its own banker's rounding helper, separate from `prorateCredit`, so changing the
  rule value alone leaves plan changes on half-even. The prompt says "every place an amount is prorated".
- `src/billing/refund.js` uses `<` for "up to and including N days" (off by one at exactly 30 days).
- Both documents claim to be authoritative ("source of truth" and "authoritative"); the prompt rule overrides both.
- `src/legacy/old-quote.js` is dead code.

## Intended resolution

Update `rules.js` (including `CANCEL_AT` and `SEAT_OVERAGE_CENTS`), make `planChangeCharge` use `prorateCredit`, fix the refund boundary, edit the losing rows in
both documents so values match, write `docs/DECISIONS.md` with the six rows, add tests and a changelog entry.
