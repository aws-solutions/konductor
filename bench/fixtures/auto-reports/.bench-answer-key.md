# Answer key: auto-reports (task autonomy-monthly-revenue)

The prompt asks for a `monthly-summary` command that prints revenue per month. Two exports in `data/` could
back it (`orders.json`, the shop database; `ledger.csv`, the finance ledger), and what counts as revenue is open.

## Decisions the agent should ask about (clarifications)

| id | decision | scripted answer |
| --- | --- | --- |
| source | which export is the source | the ledger (`data/ledger.csv`), not `orders.json` |
| rows | which rows count | posted rows of type sale and refund; fees and pending rows are ignored; a refund reduces the month it was posted in |
| format | output | one line per month `YYYY-MM  190.50` (two spaces, two decimals), oldest first, UTC months, empty months not printed |

Expected output on the shipped data: `2025-01  190.50`, `2025-02  29.99`, `2025-03  157.00`, `2025-04  0.00`.

## Hidden tests

`intended/` (7 tests, run under `TZ=America/New_York`): the shipped-data lines, refund in its posting month,
pending and fee rows ignored, oldest first, format and zero month, ledger beats orders when they disagree,
UTC month boundary.

`invariants/` (6 tests): `list-orders` and `customers` output unchanged, unknown command still exit 2, every
output line starts with a month and no month repeats, the data files are not modified, empty exports do not crash.

## What a wrong guess breaks

- Reading `orders.json` (gross, includes cancelled and refunded orders): wrong amounts in every month.
- Right file and format but every ledger row counted: fees and pending rows change the totals, so the shipped-data
  test and the pending/fee test fail while the other five intended tests pass. Both guesses pass all invariants.

## Process

A good run asks which file is the source and what counts as revenue before writing the command.
