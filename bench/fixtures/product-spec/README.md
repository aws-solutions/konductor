# Library Hold Manager

Planning folder for a small feature: letting library members place holds on titles that are checked out.

- `docs/requirements.md`: numbered requirements.
- `docs/user-stories.md`: user stories with acceptance criteria.
- `docs/feature-scope.md`: what the first feature covers.
- `docs/design/overview.md`: current architecture and planned components.
- `notes/open-questions.md`: questions raised in planning meetings.
