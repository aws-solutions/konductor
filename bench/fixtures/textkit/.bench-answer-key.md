# textkit answer key

Judge-only. Runners must not copy this file into the agent working directory.

Baseline: `node --test` reports 15 tests, 13 pass, 2 fail (exit 1).

## Seeded defects

| ID | File | Defect | Correct behavior |
|----|------|--------|------------------|
| T1 | src/slug.js | `replace(/\s/g, '-')` turns each whitespace char into a hyphen and leaves leading/trailing hyphens. Causes the 2 failing tests in test/slug.test.js. | `slugify('Hello,   World')` is `hello-world`; `slugify('-- Hello --')` is `hello`. Fix: collapse `[\s-]+` to one hyphen, then strip hyphens at the ends. |
| T2 | src/csv.js | A doubled quote `""` inside a quoted field is dropped (the quote toggle flips twice). Not covered by tests. | `parseLine('"say ""hi"""')` should be `['say "hi"']`. |
| T3 | src/csv.js | `if (current !== '') fields.push(current)` drops a trailing empty field. | `parseLine('a,b,')` should be `['a','b','']`. |
| T4 | src/csv.js | `parseCsv` splits on `\n` only, so CRLF input leaves `\r` on the last field. | Handle `\r\n`. |
| T5 | src/csv.js | `parseCsv` splits on every newline, so a quoted field containing a newline is cut in two. | Quoted newlines stay inside the field. |

## Other facts used by tasks

- `src/strings.js`: `capitalize`, `truncate`, `initials` each repeat `s.trim().replace(/\s+/g, ' ')`. Used by the refactor task (helper `normalizeSpace`).
- `src/words.js`: `cnt` is the word counter. Used by the rename task (`countWords`). `cnt` appears in src/index.js, src/words.js, test/words.test.js, README.md and CHANGELOG.md. The CHANGELOG entry is history and may stay.
- README.md has no Usage section. Correct outputs: `slugify('Hello World')` is `hello-world`; `truncate('abcdefghij', 8)` is `abcde...`; `parseLine('"a,b",c')` is `['a,b','c']`. Before the T1 fix, `slugify('Hello,   World')` is `hello---world`, so an example showing `hello-world` for that input is wrong unless the bug is fixed first.
- Version is 0.1.0; CHANGELOG top entry is 0.1.0.
