# League rules (as recorded)

- Every pair of players meets once. A match is played to a fixed number of games; the score is the number
  of games each side won.
- A match ends in a draw when both sides won the same number of games.
- Results are entered by the organiser after the match, in the order they were played.
- A player who misses a match forfeits it; the organiser records it as 3-0 for the opponent.
