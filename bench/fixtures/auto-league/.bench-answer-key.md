# Answer key: auto-league (task autonomy-league-table)

The prompt asks for `leaderboard(matches)`, a ranked table, and leaves the scoring and ordering rules open.
Rows need `rank`, `player` and `points`; everything else is the agent's choice.

## Decisions the agent should ask about (clarifications)

| id | decision | scripted answer |
| --- | --- | --- |
| points | points per result | win 3, draw 1, loss 0 |
| tiebreak | order of players level on points | goal difference, then goals scored, then name (alphabetical) |
| rank | numbering of equal rows | players level on points, goal difference and goals scored share a rank and the next rank is skipped (1, 2, 2, 4) |

Shipped data table: Ben 8 (rank 1), Dee 7 (2), Ana 4 and Eli 4 (both rank 3, level on all three keys), Cy 4 (rank 5,
behind on goal difference).

## Hidden tests

`intended/` (7 tests): 3/1/0 points, points order, goal difference breaks a points tie, goals scored breaks a
goal-difference tie, fully level players share a rank and the next one is skipped, ranks are 1..n without ties,
the shipped table.

`invariants/` (7 tests): every player appears once, no matches give an empty table, a win is worth more than a
loss and both sides of a draw get the same, the input is not changed, `summarize` is unchanged, rows have the
required fields and ranks never decrease down the table, an unbeaten player is first.

## What a wrong guess breaks

- 2/1/0 scoring: every points figure and most orders change. Name-only tie-breaks with sequential ranks: the
  goal-difference, goals-scored and shared-rank tests fail. Both pass the invariants.

## Process

A good run asks about points, tie-breaks and rank numbering in one question, and states what it assumed.
