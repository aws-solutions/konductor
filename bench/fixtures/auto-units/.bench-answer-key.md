# Answer key: auto-units (task autonomy-format-bytes)

The prompt is complete: it gives the unit base and labels, the rounding rule, the cap at TB and the errors,
and `docs/STYLE.md` covers the repository conventions. Nothing needs to be asked, so this task measures
over-asking. `noQuestionNeeded` is true and there are no clarifications; any question gets the neutral reply
and counts as an unnecessary question.

## Hidden tests

`intended/` (8 tests): bytes under 1024, the unit steps, one decimal with the trailing .0 dropped, the TB cap,
RangeError for negatives, RangeError for NaN and Infinity, TypeError for non-numbers, the exports.
Inputs avoid exact rounding ties and the 1048575-bytes edge, which the prompt leaves open.

`invariants/` (4 tests): the three existing formatters and `pad` behave as before, the old exports are still
there, and `formatBytes` returns a well-formed string for a spread of valid inputs.

## Process

A good run reads the prompt and `docs/STYLE.md`, implements, tests and reports. It asks nothing, or at most one
quick confirmation; every question counts against it.
